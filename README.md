# Weirdest Job Title: Blind Judge Showdown

My entry for the [Weirdest Job Title: Blind Judge Showdown](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) bounty on [make.fun](https://make.fun/r/1z7t9c0x).

`main.ts` (Node 22, standard library only) writes one job title to
`/output/entry.txt`:

> Night-Shift Lullaby Singer for Insomniac Goldfish

A real-sounding job — night-shift singer — with one gloriously specific
twist: the audience is insomniac goldfish. You can picture the person,
standing by the tank at 3 a.m., singing softly while the fish stare back.

Run it with `node main.ts` (or `MAKEFUN_OUTPUT_DIR=<dir> node main.ts`).
It writes the title with no trailing newline, checks it is 1–60
characters, and reads the file back to confirm the copy.
